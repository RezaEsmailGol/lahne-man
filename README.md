**لحن من (Lahne Man)** یک Skill متن‌باز و فارسی‌محور برای ویرایش متن است. هدفش این نیست که همهٔ نوشته‌ها را رسمی، ادبی یا شبیه یک «متن خوبِ استاندارد» کند؛ هدف این است که نشانه‌های کلیشه‌ای و ماشینی را کم کند، در حالی که صدای واقعی نویسنده باقی بماند.

اگر متن شما محاوره‌ای، رسمی، فنی، تبلیغاتی، آموزشی یا ترکیبی از فارسی و انگلیسی باشد، «لحن من» تلاش می‌کند با **کمترین تغییر مؤثر** آن را طبیعی‌تر کند؛ بدون ساختن آمار، منبع، ادعا، مثال یا نظر تازه.

> **نکته:** «لحن من» ابزار تشخیص قطعی اینکه یک متن توسط انسان یا هوش مصنوعی نوشته شده نیست. حالت بررسی فقط الگوهای سبکی قابل مشاهده را گزارش می‌کند.

## چرا «لحن من»؟

بسیاری از ابزارهای بازنویسی، متن را بیش از حد صاف و یکدست می‌کنند. نتیجه ممکن است از نظر نگارشی درست باشد، اما دیگر شبیه نویسندهٔ اصلی نیست.

«لحن من» برعکس عمل می‌کند: چیزهایی مثل شوخی، تردید، صراحت، محاوره، تکه‌جمله، اصطلاحات فنی و حتی بعضی ناهماهنگی‌های طبیعی را بخشی از هویت متن می‌داند و بی‌دلیل حذفشان نمی‌کند.

## در یک نگاه

| قابلیت | رفتار «لحن من» |
| --- | --- |
| حفظ لحن شخصی | واژگان، ریتم و سطح رسمی/محاوره‌ای متن تا جای ممکن حفظ می‌شود |
| کاهش کلیشه‌های ماشینی | مقدمه‌های عمومی، اغراق، تکرار، تقارن و پایان‌بندی مصنوعی کم می‌شوند |
| متن فنی | کد، URL، نام متغیرها، نسخه‌ها، نام ابزارها و فرمان‌های ترمینال محافظت می‌شوند |
| متن ترکیبی | فارسی و انگلیسی بی‌دلیل به یک سبک واحد تبدیل نمی‌شوند |
| حالت بررسی | کلیشه‌ها گزارش می‌شوند، بدون بازنویسی کامل متن |
| حداقل تغییر | اگر متن از قبل طبیعی باشد، تغییر کم یا حتی صفر قابل قبول است |
| بدون جعل محتوا | ادعا، منبع، عدد، آمار و واقعیت تازه ساخته نمی‌شود |
| متن‌باز | کد و قواعد پروژه با مجوز MIT در دسترس‌اند |

## چه چیزهایی را اصلاح می‌کند؟

- مقدمه‌های کم‌اطلاعات مثل «در دنیای امروز»، «لازم به ذکر است» و «حقیقت این است که» وقتی چیزی به متن اضافه نمی‌کنند.
- بزرگ‌نمایی‌های بی‌پشتوانه مثل «انقلابی»، «نقطه عطف»، «بی‌نظیر» و «تحول‌آفرین».
- جمله‌های کوتاه و ضربه‌ای پشت‌سرهم، سه‌تایی‌های کلیشه‌ای و تقارن بیش از حد.
- نسبت دادن مبهم مثل «کارشناسان معتقدند» یا «تحقیقات نشان می‌دهد» وقتی منبعی وجود ندارد.
- جمع‌بندی‌های تکراری و پایان‌های فلسفی یا تبلیغاتی مصنوعی.
- خطاهای واضح نیم‌فاصله و حروف فارسی، بدون رسمی‌سازی اجباری متن.

## Skill چیست؟

Skill یک مجموعه دستور و راهنمای قابل‌استفاده مجدد برای یک عامل هوش مصنوعی است. «لحن من» برنامهٔ مستقل یا اپلیکیشن موبایل نیست؛ وقتی در محیط سازگار نصب یا اضافه شود، مدل می‌داند هنگام ویرایش متن چه قواعدی را رعایت کند.

بنابراین سؤال «روی گوشی نصب می‌شود یا سیستم؟» به محیط میزبان بستگی دارد: ابزارهای توسعه مثل Codex و Claude Code معمولاً از کامپیوتر و ترمینال استفاده می‌کنند، ولی سرویس‌هایی که Custom Skill را از داخل رابط خود می‌پذیرند می‌توانند مسیر متفاوتی داشته باشند.

## نصب

### روش عمومی با ابزار `skills`

اگر محیط شما Agent Skills را پشتیبانی می‌کند و Node.js در دسترس است:

```bash
npx skills add RezaEsmailGol/lahne-man --skill lahne-man --global --yes
```

برای نصب فقط در پروژهٔ جاری:

```bash
npx skills add RezaEsmailGol/lahne-man --skill lahne-man --yes
```

### Claude Code

روش پیشنهادی از طریق Plugin Marketplace:

```text
/plugin marketplace add RezaEsmailGol/lahne-man
/plugin install lahne-man@lahne-man
```

یا از ترمینال:

```bash
npx skills add RezaEsmailGol/lahne-man --skill lahne-man --global --yes
```

صرفاً فرستادن جملهٔ «Install the skill...» داخل چت روش تضمین‌شدهٔ نصب در همهٔ نسخه‌ها و محیط‌ها نیست.

### claude.ai

در نسخه‌هایی از claude.ai که Custom Skills را پشتیبانی می‌کنند، Skill را از بخش مربوط به Features/Skills مطابق رابط همان سرویس اضافه یا بارگذاری کنید.

### ChatGPT و Codex

مخزن برای ساختار Plugin/Skill جدید OpenAI آماده شده و علاوه بر manifest سازگاری Codex، manifest قابل‌حمل `plugin.json` را نیز دارد. پس از انتشار عمومی در Plugin Directory، نصب از مسیر رسمی Directory ساده‌تر خواهد شد.

## استفاده سریع

### ویرایش طبیعی متن

```text
/lahne-man

این متن را طبیعی‌تر کن و لحن من را حفظ کن:
[متن شما]
```

### فقط بررسی، بدون بازنویسی

```text
/lahne-man

فقط بررسی کن چه کلیشه‌های ماشینی در این متن وجود دارد.
متن را بازنویسی نکن:
[متن شما]
```

### حفظ لحن محاوره‌ای

```text
/lahne-man

این متن را ویرایش کن، ولی لحن محاوره‌ای من،
کلمات خودم و ریتم جمله‌ها را حفظ کن:
[متن شما]
```

### متن فنی

```text
/lahne-man

این توضیح فنی را طبیعی‌تر کن.
کد، URL، نام متغیرها، نسخه‌ها و نام ابزارها را تغییر نده:
[متن شما]
```

### کپشن و متن تبلیغاتی

```text
/lahne-man

این کپشن را از حالت تبلیغاتیِ ماشینی خارج کن.
CTA را نگه دار، ولی مشخص و طبیعی‌اش کن:
[متن شما]
```

## دو حالت اصلی

### 1. ویرایش

حالت پیش‌فرض است. متن با حداقل تغییر مؤثر طبیعی‌تر می‌شود و معنی، موضع، داده و جزئیات واقعی آن حفظ می‌شوند.

اگر کاربر قالب خاصی درخواست نکرده باشد، Skill می‌تواند بعد از متن نهایی یک توضیح کوتاه از تغییرات مهم بدهد. اگر کاربر بگوید «فقط متن نهایی»، همان درخواست مقدم است.

### 2. بررسی

برای زمانی است که فقط می‌خواهید بدانید کدام بخش‌ها کلیشه‌ای، بیش‌ازحد ماشینی یا کم‌اطلاعات‌اند. در این حالت متن کامل بازنویسی نمی‌شود و دربارهٔ هویت نویسنده قضاوت قطعی صورت نمی‌گیرد.

## چه چیزهایی عمداً حفظ می‌شوند؟

عبارت‌هایی مثل «فکر می‌کنم»، «شاید»، «به نظرم»، شوخی، محاوره، مکث، تکه‌جمله، اصطلاحات تخصصی و سبک شخصی نویسنده لزوماً ایراد نیستند. «لحن من» فقط برای یکدست و رسمی کردن متن آن‌ها را حذف نمی‌کند.

همچنین دستورها یا Promptهایی که داخل **متن هدف** قرار گرفته‌اند صرفاً محتوا محسوب می‌شوند و نباید به‌عنوان فرمان اجرایی تفسیر شوند.

## نمونهٔ رفتار

**قبل:**

> در دنیای امروز، هوش مصنوعی به‌عنوان یک فناوری انقلابی نقش بسزایی در تغییر زندگی ما ایفا می‌کند. حقیقت این است که این فناوری می‌تواند فرصت‌های بی‌نظیری ایجاد کند.

**بعد، با حفظ معنی و بدون بزرگ‌نمایی اضافه:**

> هوش مصنوعی در سال‌های اخیر روی بخش‌های مختلف زندگی و کار اثر گذاشته است. اگر درست و آگاهانه استفاده شود، می‌تواند در بعضی کارها مفید باشد و فرصت‌های تازه‌ای ایجاد کند.

این فقط یک نمونه است؛ Skill نباید همهٔ متن‌ها را به همین لحن تبدیل کند و باید لحن ورودی را مبنا قرار دهد.

## ساخت و اعتبارسنجی بستهٔ افزونه

ساخت بسته:

```bash
python scripts/build_plugin.py
```

خروجی در پوشهٔ `dist` ساخته می‌شود.

فقط اعتبارسنجی سورس:

```bash
python scripts/build_plugin.py --check
```

اسکریپت preflight مواردی مثل manifestها، نسخه، URLهای HTTPS، طول metadata، Promptهای آغازین، رنگ برند، آیکن و ساختار ZIP را بررسی می‌کند.
