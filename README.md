# لحن من

**لحن من** یک مهارت متن‌باز برای ویرایش متن فارسی است که کلیشه‌های ماشینی و الگوهای رایج نوشته‌های تولیدشده با هوش مصنوعی را کم می‌کند، بدون اینکه صدای واقعی نویسنده را صاف و یکدست کند.

اگر متن شما محاوره‌ای، رسمی، فنی، تبلیغاتی، آموزشی یا ترکیبی از فارسی و انگلیسی باشد، «لحن من» تلاش می‌کند همان سبک را حفظ کند و فقط چیزهایی را تغییر دهد که واقعاً متن را مصنوعی، تکراری یا مبهم کرده‌اند.

> «لحن من» ابزار تشخیص قطعی نویسنده انسانی یا هوش مصنوعی نیست. این پروژه الگوهای قابل مشاهده در متن را بررسی می‌کند، نه هویت نویسنده را.

## چه کارهایی انجام می‌دهد؟

- حذف مقدمه‌های کلیشه‌ای مثل «در دنیای امروز»، «لازم به ذکر است» و «حقیقت این است که» وقتی اطلاعاتی اضافه نمی‌کنند.
- کم کردن بزرگ‌نمایی‌هایی مثل «انقلابی»، «نقطه عطف»، «بی‌نظیر» و «تحول‌آفرین» وقتی پشتوانه‌ای ندارند.
- اصلاح ریتم رباتیک، جمله‌های ضربه‌ای پشت‌سرهم، تقارن بیش‌ازحد و سه‌تایی‌های کلیشه‌ای.
- حذف نسبت دادن مبهم مثل «کارشناسان معتقدند» یا «تحقیقات نشان می‌دهد» وقتی منبعی وجود ندارد.
- حذف جمع‌بندی‌های تکراری و پایان‌های فلسفی مصنوعی.
- حفظ لحن محاوره‌ای، شوخی، تردید، صراحت، اصطلاحات فنی و ویژگی‌های شخصی نویسنده.
- محافظت از کد، URL، نام متغیر، نام محصول، نسخه نرم‌افزار و دستورهای ترمینال.
- اصلاح خطاهای واضح نیم‌فاصله و حروف فارسی، بدون رسمی‌سازی اجباری متن.

## نصب سریع

ساده‌ترین روش این است که این دستور را به ChatGPT، Codex، Claude Code یا عامل کدنویسی سازگار با Skills بدهید:

```text
Install the /lahne-man skill globally from https://github.com/RezaEsmailGol/lahne-man
```

یا با ابزار `skills`:

```bash
npx skills add RezaEsmailGol/lahne-man --skill lahne-man --global --yes
```

برای نصب محلی در یک پروژه، گزینه `--global` را حذف کنید:

```bash
npx skills add RezaEsmailGol/lahne-man --skill lahne-man --yes
```

## استفاده سریع

### ویرایش متن

```text
/lahne-man
این متن را طبیعی‌تر کن و لحن من را حفظ کن:
[متن شما]
```

در حالت عادی، «لحن من» متن را با کمترین تغییر مؤثر بازنویسی می‌کند و در پایان چند تغییر اصلی را توضیح می‌دهد.

### فقط بررسی، بدون بازنویسی

```text
/lahne-man
فقط بررسی کن چه کلیشه‌های ماشینی در این متن وجود دارد. متن را بازنویسی نکن:
[متن شما]
```

در این حالت، نام الگو، بخش کوتاهی از متن و پیشنهاد اصلاح را می‌بینید؛ متن کامل بازنویسی نمی‌شود.

### حفظ لحن محاوره‌ای

```text
/lahne-man
این متن را ویرایش کن، ولی لحن محاوره‌ای من، کلمات خودم و ریتم جمله‌ها را حفظ کن:
[متن شما]
```

### متن فنی

```text
/lahne-man
این توضیح فنی را طبیعی‌تر کن. کد، URL، نام متغیرها، نسخه‌ها و نام ابزارها را تغییر نده:
[متن شما]
```

### کپشن و متن تبلیغاتی

```text
/lahne-man
این کپشن را از حالت تبلیغاتیِ ماشینی خارج کن. CTA را نگه دار، ولی مشخص و طبیعی‌اش کن:
[متن شما]
```

## دو حالت اصلی

**ویرایش** حالت پیش‌فرض است. متن اصلاح می‌شود، اما معنی، موضع، عدد، مثال و ادعای تازه‌ای نباید ساخته شود.

**بررسی** برای زمانی است که فقط می‌خواهید بدانید کدام الگوها مصنوعی یا کلیشه‌ای‌اند. در این حالت متن بازنویسی نمی‌شود و درباره اینکه نویسنده انسان یا هوش مصنوعی بوده قضاوتی صورت نمی‌گیرد.

## چه چیزهایی عمداً حفظ می‌شوند؟

«لحن من» قرار نیست همه متن‌ها را شبیه یک ویراستار رسمی کند. عبارت‌هایی مثل «فکر می‌کنم»، «شاید»، «به نظرم»، جمله‌های محاوره‌ای، شوخی، تکه‌جمله، مکث و حتی بعضی ناهماهنگی‌های طبیعی می‌توانند بخشی از صدای نویسنده باشند و نباید بی‌دلیل حذف شوند.
