# راهنمای کامل استفاده از «لحن من»

این راهنما توضیح می‌دهد چه زمانی از «لحن من» استفاده کنید، چه دستوری بدهید و چه خروجی‌ای انتظار داشته باشید.

## ۱. ویرایش معمولی

برای بیشتر متن‌ها کافی است بنویسید:

```text
/lahne-man
این متن را طبیعی‌تر کن و لحن من را حفظ کن:

[متن]
```

ابزار ابتدا سبک متن را تشخیص می‌دهد، سپس فقط بخش‌هایی را تغییر می‌دهد که کلیشه‌ای، مبهم، تکراری یا بیش‌ازحد ماشینی‌اند.

## ۲. وقتی نمی‌خواهید متن بازنویسی شود

اگر فقط می‌خواهید مشکلات را ببینید:

```text
/lahne-man
فقط بررسی کن. متن را بازنویسی نکن. کلیشه‌های ماشینی را با مثال نشان بده:

[متن]
```

خروجی باید شامل نام الگو، یک نقل‌قول کوتاه و پیشنهاد اصلاح باشد.

## ۳. حفظ لحن شخصی

اگر سبک خاصی دارید، آن را صریح بگویید:

```text
/lahne-man
لحن من کوتاه، مستقیم و کمی محاوره‌ای است. متن را رسمی نکن و فقط بخش‌های مصنوعی را اصلاح کن:

[متن]
```

همین روش برای لحن رسمی، اداری، آموزشی، طنز، تخصصی یا فروش هم قابل استفاده است.

## ۴. ویرایش متن‌های فنی

برای مستندات فنی بهتر است محدودیت‌ها را مشخص کنید:

```text
/lahne-man
این متن فنی را ویرایش کن. نام کلاس‌ها، متغیرها، API، URL، فرمان‌ها، نسخه‌ها و بلوک‌های کد را تغییر نده:

[متن]
```

«لحن من» باید متن توضیحی اطراف کد را اصلاح کند و خود داده فنی را دست‌نخورده نگه دارد.

## ۵. کپشن شبکه اجتماعی

```text
/lahne-man
این کپشن را طبیعی‌تر کن. لحن فروش را نگه دار، اما اغراق، شعار و CTA کلیشه‌ای را کم کن:

[کپشن]
```

اگر CTA لازم است، بهتر است یک اقدام واقعی و مشخص بماند؛ مثل «برای دریافت قیمت، مدل را در دایرکت بفرستید.»

## ۶. مقاله و محتوای سایت

```text
/lahne-man
این بخش مقاله را ویرایش کن. اطلاعات و کلیدواژه‌های تخصصی را حفظ کن، مقدمه‌های کلیشه‌ای و تکرارهای غیرضروری را حذف کن:

[متن]
```

برای محتوای سئو، می‌توانید اضافه کنید:

```text
کلیدواژه اصلی و عبارت‌های مهم سئو را حذف یا با مترادف جایگزین نکن.
```

## ۷. نامه و متن اداری

```text
/lahne-man
این نامه را روان‌تر کن، ولی لحن رسمی و اداری آن را حفظ کن. اصطلاحات حقوقی یا سازمانی را ساده‌سازی نکن مگر واقعاً اضافه باشند:

[متن]
```

در متن اداری، عبارت‌هایی مثل «می‌باشد» همیشه اشتباه نیستند. «لحن من» باید قالب متن را در نظر بگیرد.

## ۸. مقایسه قبل و بعد

اگر می‌خواهید تغییرات را دقیق‌تر ببینید:

```text
/lahne-man
نسخه ویرایش‌شده را بده و بعد فقط ۵ تغییر مهم را به صورت قبل ← بعد نشان بده:

[متن]
```

## ۹. ویرایش حداقلی

اگر متن از قبل خوب است:

```text
/lahne-man
ویرایش خیلی سبک انجام بده. فقط مواردی را تغییر بده که واقعاً مصنوعی یا مبهم‌اند:

[متن]
```

## ۱۰. چه درخواست‌هایی مناسب نیستند؟

«لحن من» برای تشخیص قطعی اینکه یک متن را انسان یا AI نوشته مناسب نیست. به جای «این متن چند درصد هوش مصنوعی است؟» بپرسید:

```text
/lahne-man
کدام الگوهای این متن شبیه نوشتار ماشینی یا کلیشه‌ای هستند؟
```

این سؤال قابل بررسی و توضیح است.

## خروجی استاندارد در حالت ویرایش

خروجی معمولاً دو بخش دارد:

1. متن کامل ویرایش‌شده؛
2. بخش کوتاه «چه چیزهایی تغییر کرد» با ۲ تا ۵ تغییر اصلی.

## خروجی استاندارد در حالت بررسی

در حالت بررسی، خروجی باید شبیه این باشد:

```text
الگوهای پیدا شده

- شروع کلیشه‌ای — «در دنیای امروز...» — مستقیم با موضوع شروع شود.
- بزرگ‌نمایی — «راهکاری انقلابی» — ویژگی واقعی جایگزین شود.
- نسبت مبهم — «کارشناسان معتقدند» — منبع مشخص شود یا جمله حذف شود.
```

## نکته مهم

هدف «لحن من» این نیست که متن را بی‌نقص، یکدست یا بیش‌ازحد رسمی کند. متن خوب باید هنوز شبیه کسی باشد که آن را نوشته است.
